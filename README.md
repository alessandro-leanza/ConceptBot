# ConceptBot
## Abstract
The integration of Large Language Models (LLMs) into robotics is enhancing robots' ability to interpret human instructions and execute complex tasks. However, deploying LLMs in unstructured environments presents challenges like task ambiguity and contextual comprehension.
To address these challenges, this paper introduces ConceptBot, a novel planning system that integrates LLMs with Knowledge Graphs (KGs), particularly ConceptNet, to enhance task decomposition and context understanding. ConceptBot employs a modular architecture consisting of three components: Object Properties Extraction (OPE), User Request Processing (URP), and the Planner. OPE extracts task-relevant object properties using KGs for improved scene understanding. URP interprets natural language instructions, leveraging KGs to determine user needs. The Planner integrates this information to generate feasible and context-aware pick-and-place policies.
